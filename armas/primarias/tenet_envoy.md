# Tenet Envoy

> [!info] Resumo
> Arma **primária** (Launcher), **MR 16**, dano principal **Impacto**, introduzida no Update 30.5.

## 🌍 Onde Conseguir — Tenet Envoy

Como conseguir a arma Tenet Envoy:

Tenet Envoy é uma **arma Tenet**: só se obtém **derrotando (vanquish) uma Sister of Parvos** gerada com ela. Depois, ela aparece pronta na Foundry. Não é negociável, mas uma Sister convertida com ela pode ser trocada no Crimson Branch do Dojo.
