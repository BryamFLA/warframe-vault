# Tenet Tetra

> [!info] Resumo
> Arma **primária** (Rifle), **MR 16**, dano principal **Perfuração**, introduzida no Update 30.5.

## 🌍 Onde Conseguir — Tenet Tetra

Como conseguir a arma Tenet Tetra:

Tenet Tetra é uma **arma Tenet**: só se obtém **derrotando (vanquish) uma Sister of Parvos** gerada com ela. Depois, ela aparece pronta na Foundry. Não é negociável, mas uma Sister convertida com ela pode ser trocada no Crimson Branch do Dojo.
