# Deth Machine Rifle

> [!info] Resumo
> Arma **Robotic** (Rifle), **MR 0**, dano principal **Corte**, introduzida no Update 8.0.

## 🌍 Onde Conseguir — Deth Machine Rifle

Como conseguir a arma Deth Machine Rifle:

Arma robótica que vem **automaticamente** com o Sentinel **Dethcube**. Ocupa 1 slot de companheiro.
