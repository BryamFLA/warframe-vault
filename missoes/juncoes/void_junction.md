# Void — acesso (sem Junção)

> [!info] Resumo
> O Void não tem Junção: todos os caminhos que levam a ele são livres, bastando ter os nós das duas pontas desbloqueados.

---

> [!warning] Este destino NÃO tem Junção
> A wiki é explícita: **certos caminhos entre destinos não têm Junções** e podem ser atravessados assim que os nós das duas pontas estiverem desbloqueados. São eles:
>
> - **todos os caminhos que levam ao [[locais/planetas/void.md|Void]]**
> - **o caminho da [[locais/planetas/terra.md|Terra]] para [[locais/planetas/lua.md|Lua]]**
> - **o caminho de [[locais/planetas/marte.md|Marte]] para [[locais/planetas/deimos.md|Deimos]]**
>
> Este arquivo existe no vault com nome de Junção, mas **não há Junção correspondente no jogo**. O conteúdo abaixo documenta **como o destino é realmente desbloqueado**.


## 🎯 Objetivo — Void — acesso (sem Junção)


| Item | Detalhe |
|---|---|
| Destino | **Void** — ver [[locais/planetas/void.md\|Void]] |
| Como desbloquear | **Nenhuma Junção.** Todos os caminhos que levam ao Void são atravessáveis assim que os nós vizinhos estiverem abertos |
| Guardião de Junção | **Não existe** |
| Mastery de Junção | **Não se aplica** |


## 🔓 Como o acesso realmente acontece — Void — acesso (sem Junção)


O **[[locais/planetas/void.md|Void]]** é um caso especial do Star Chart:

| Item | Detalhe |
|---|---|
| Faixa de nível | **10 – 45** |
| Missões | **13** |
| Facção | **[[lore/faccoes/orokin.md\|Orokin]]** (inimigos **Corrupted**) |
| Chefe | **[[lore/chefes/corrupted_vor.md\|Corrupted Vor]]** — aparece em **qualquer nó de nível ≥ 40** |
| Recursos | Ferrite · Rubedo · **Argon Crystal** · Control Module |
| Mods exclusivos | Malignant Force · Toxic Barrage · Virulent Scourge · Pistol Pestilence |

O que destrava o Void na prática é **progredir pelo Star Chart até alcançar um nó adjacente a ele**. Não há tarefa, nem Specter, nem Mastery de Junção.

> [!important] Argon Crystal decai
> O **Argon Crystal**, recurso exclusivo do Void, é o único recurso do jogo que **decai com o tempo** depois de coletado. Colha quando for usar, não para estocar.


## 💡 Dicas — Void — acesso (sem Junção)


- Se você está procurando as Junções de verdade, elas são **13**: Vênus, Mercúrio, Marte, Phobos, Ceres, Júpiter, Europa, Saturno, Urano, Netuno, Plutão, Eris e Sedna. Cada uma dá **1.000 de Mastery**.
- Junções podem ser usadas como **atalho** entre corpos celestes na navegação do Star Chart.
- As tarefas de Junção **só impedem de lutar contra o Specter**, não de entrar na Junção. E **Specters podem ser escaneados** mesmo quando você não pode atacá-los.
- Specters de Junção dão aproximadamente **2.000 de afinidade** ao morrer.
