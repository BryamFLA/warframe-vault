# Glossário

> [!info] Em uma linha
> Tradução das siglas e gírias que aparecem no chat, em guias e em builds. Os termos ficam em inglês (como o jogador usa); a explicação em português. A página original da wiki avisa que parte desse vocabulário é da comunidade, não oficial da Digital Extremes.

## 🔤 Stats e Mecânicas — Glossário

| Termo | Significado |
|---|---|
| 1, 2, 3, 4 | Habilidades do Warframe pela ordem ("o 4 do Excalibur" = Exalted Blade). **Ult / Ultimate** = a 4ª |
| Str / Dur / Eff / Range | Ability Strength / Duration / Efficiency / Range |
| Affinity, XP | Experiência que sobe o rank de armas, Warframes e companheiros |
| CC | Crowd Control (controle de multidão) — ou Critical Chance, conforme o contexto ([[mecanicas/critico.md\|Crítico]]) |
| DoT | Dano ao longo do tempo (procs de Toxin, Electricity, Slash) |
| DPS | Dano por segundo; "frame de DPS" = frame que mata consistentemente |
| DR | Damage Reduction (redução de dano) |
| AoE | Área de efeito |
| Proc | Ativação de um Status Effect (vem de *Programmed Random Occurrence*). Ver [[mecanicas/dano_e_status.md\|Dano e Status]] |
| Stack, Stacking | Uma instância de buff/debuff; acumular várias (aditiva ou multiplicativa) |
| Strip, Stripping | Reduzir ou zerar a armadura do inimigo |
| Buff / Nerf | Fortalecer / enfraquecer (efeito temporário ou mudança de balanceamento) |
| Debuff | Efeito negativo temporário |
| Aggro | Nível de ameaça; atrair o fogo inimigo para si |
| LoS | Line of Sight (linha de visão); algumas habilidades exigem |
| Diminishing returns | Bônus aditivos que rendem proporcionalmente menos quanto mais você empilha |
| Maxed / Unranked | Mod ou Arcane no rank máximo / no rank 0 |
| Infusion | Habilidades que dão elemento às armas do squad (ex.: Venom Dose, Smite Infusion) |
| Subsume | Sacrificar um Warframe ao [[mecanicas/helminth.md\|Helminth]] para aprender a habilidade; na comunidade, também a habilidade infundida |

## 🎒 Itens e Recursos — Glossário

| Termo | Significado |
|---|---|
| Potato · Blue Potato · Gold Potato | [[recursos/raridades/especial/orokin_catalyst.md\|Orokin Catalyst]] (azul, armas) e [[recursos/raridades/especial/orokin_reactor.md\|Orokin Reactor]] (dourado, Warframes); dobram a capacidade de mod |
| Cell, OC, OroCell | Orokin Cell (recurso raro) |
| Shard | [[mecanicas/archon_shards.md\|Archon Shard]] |
| Plat, Pl, P | [[mecanicas/platinum.md\|Platinum]], a moeda premium (negociável) |
| BP | Blueprint |
| Set | Todas as peças de um item (ex.: set de Nova Prime = BP + Neuroptics + Chassis + Systems); ou Set Mods |
| Mats | Recursos de crafting |
| Relic | [[mecanicas/reliquias_do_void.md\|Void Relic]] |
| Prime | Versão Orokin de um item, geralmente mais forte e com mais polaridades |
| Corrupted Mods | Mods com bônus e penalidade, vindos dos Orokin Vaults ([[mecanicas/modding.md\|Modding]]) |
| 60/60 | Mods duplos de elemento + Status Chance (60% cada no máximo), ex.: Frostbite |
| Bane Mods | Mods de dano por facção |
| Clantech | Itens pesquisados no Dojo do clã |
| Primed Disappointment | Piada: o "mod" que o Baro traz quando o estoque é ruim |

## 💬 Gírias da Comunidade — Glossário

| Termo | Significado |
|---|---|
| Meta | Estratégia/loadout mais eficiente do momento |
| Build | Configuração de mods de um item |
| Kit | Conjunto de habilidades de um Warframe; ou o loadout |
| Main | Jogar principalmente com um Warframe |
| Tank | Frame/jogador que aguenta muito dano |
| Glass Cannon | Muito dano, pouca sobrevivência |
| Nuke | Arma/habilidade que mata muitos de uma vez |
| Primer | Arma usada para espalhar vários status antes do dano (para Condition Overload, Galvanized Aptitude) |
| Stat Stick | Arma equipada só para emprestar seus mods/stats a outra coisa (ex.: melee para habilidades exaltadas) |
| Mastery Fodder | Arma fraca, upada só para Mastery e vendida no rank 30 |
| Fashion Frame | Customização visual do Warframe |
| Trash | Inimigos fracos |
| Grind / Farm | Repetir atividades para juntar itens |
| RNG | Aleatoriedade (drops) |
| Pug, Pubs | Squad público, não combinado |
| Hallway Hero | Quem luta longe do objetivo em Defense/Survival, espalhando XP e loot |
| Leech | Quem não contribui na missão |
| Evergreen | Recompensa sempre útil/sempre disponível (ex.: Orokin Reactor na Nightwave) |
| Rework | Reformulação de uma mecânica ou das habilidades de um frame |
| Redtext | Avisos em vermelho da DE no chat |
| WTB / WTS / WTT | Quero comprar / vender / trocar ([[mecanicas/trading.md\|Trading]]) |
| DE | Digital Extremes, a desenvolvedora |
| EV | Build de Trinity focada em Energy Vampire |
