# Arcanes (Arcane Enhancements)

> [!info] Em uma linha
> Arcanes são bônus com **gatilho e chance**: cumpriu a condição (crítico, pegar energia, levar dano…), há X% de chance de ativar o efeito. São equipados em slots próprios, separados dos mods, e sobem de rank consumindo cópias.

## ⚙️ Como Funciona — Arcanes

| Equipamento | Slots de Arcane |
|---|---|
| Warframe | 2 (só 1 se usar Arcane Helmet) |
| Operator | 2 |
| Amp | 2 |
| Primária / Secundária / Melee | 1 |
| Zaw / Kitgun | 1 slot próprio, separado do slot de Primary/Secondary/Melee |
| Arch-gun | 2 (um Primary e um Secondary) |
| Arma de Sentinel, Archwing, Archmelee, Necramech | Nenhum |

- Duração de efeito renovável é reiniciada a cada nova ativação.
- O mesmo Arcane pode ser usado em vários itens, mas não duplicado no mesmo item.
- Upgrade fica no **Arcane Segment** do Orbiter (ESC → EQUIPMENT → ARCANES).
- Arcanes que caem de inimigos contam como **drop de mod** → afetados por Steel Path e Mod Drop Booster.
- Bônus "Primary" só valem para primárias; "Secondary" só para secundárias.

## 🔢 Fórmulas e Números — Arcanes

```
Cópias totais para o rank n = (n + 1)(n + 2) / 2
Rank:            0   1   2   3    4    5
Cópias (total):  1   3   6   10   15   21
```

| Família | Rank máximo | Cópias para maximizar |
|---|---|---|
| Warframe, Primary, Secondary, Melee, Operator, Eternal | 5 | 21 |
| Exodia, Virtuos, Pax, Residual | 3 | 10 |

## 📋 Tabelas de Referência — Arcanes

### Dissolução com Loid (Vosfor)

Depois da quest [[missoes/jornadas/principais/whispers_in_the_walls.md|Whispers in the Walls]], [[lore/personagens/loid.md|Loid]] (Sanctum Anatomica) dissolve Arcanes em [[recursos/raridades/especial/vosfor.md|Vosfor]]. Cada coleção custa **200 Vosfor + 50.000 Credits** e dá **3 Arcanes** (chance independente por slot).

| Coleção | Chances por slot |
|---|---|
| Cavia | 45% Uncommon · 50% Rare · 5% Legendary |
| Duviri | 45% Uncommon · 50% Rare · 5% Legendary |
| Eidolon | 40% Common · 35% Uncommon · 20% Rare · 5% Legendary (Barrier, Energize, Grace: 1,67% cada) |
| Holdfasts | 100% Rare |
| Höllvania | 95% Rare · 5% Legendary |
| Necralisk | 100% Rare |
| Ostron | 10% Common · 30% Uncommon · 60% Rare |
| Solaris | 60% Common · 30% Uncommon · 10% Rare |
| Steel | 100% Rare |

### De onde vêm (por família)

O nome da coleção do Loid indica a origem do Arcane. Os pontos de farm de cada um estão no arquivo do próprio Arcane.

| Família | Região de origem |
|---|---|
| Eidolon (ex.: Arcane Energize, Grace, Barrier) | Eidolons das Plains of Eidolon ([[locais/open-worlds/cetus.md\|Cetus]]) |
| Ostron / Solaris | [[locais/open-worlds/cetus.md\|Cetus]] / [[locais/open-worlds/fortuna.md\|Fortuna]] |
| Steel (Primary/Secondary Merciless, Deadhead, Dexterity) | Acolytes do [[mecanicas/steel_path.md\|Steel Path]] |
| Necralisk | [[locais/open-worlds/deimos.md\|Deimos]] |
| Holdfasts | [[locais/open-worlds/zariman.md\|Zariman]] |
| Cavia | Sanctum Anatomica (Albrecht's Laboratories) |
| Duviri | [[locais/open-worlds/duviri.md\|Duviri]] |
| Höllvania | [[locais/hollvania.md\|Höllvania]] |

Cada Arcane tem arquivo próprio em `mods/arcanes/` com efeito no rank máximo e fontes de drop (ex.: [[mods/arcanes/arcane_energize.md|Arcane Energize]], [[mods/arcanes/arcane_grace.md|Arcane Grace]], [[mods/arcanes/molt_augmented.md|Molt Augmented]], [[mods/arcanes/primary_merciless.md|Primary Merciless]]).

## 💡 Dicas Práticas — Arcanes

- Arcane só vale com **rank alto**: um rank 0 tem efeito bem menor. Priorize maximizar 1 Arcane útil antes de espalhar vários pela metade.
- Trocar Legendary Arcanes (Barrier, Grace, Energize, Exodia Contagion/Epidemic, Arcane Reaper, Longbow Sharpshot, Secondary Shiver, Melee Crescendo, Melee Duplicate, Arcane Universal Fallout, Arcane Hot Shot, Arcane Escapist) exige **MR 11**.
- No Steel Path, os Scavenger Drones destroem Arcanes dropados por Acolytes — mate os drones antes.
- Duplicatas inúteis → Vosfor → coleção do Loid é o jeito de "reciclar".
