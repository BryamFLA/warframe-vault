# Longwinder

> [!info] Resumo
> Peixe raro, encontrado em **Orb Vallis (Vênus), Lake Hotspot during Warm cycle with Longwinder Bait, using Shockprod / Stunna peixesing spear**.
> *Descrição no jogo (inglês):* "Repairs leaks and clear blockages within the aqua systems. It can be found in the lake on Venus."

**Como conseguir Longwinder:** aparece em **Orb Vallis (Vênus), Lake Hotspot during Warm cycle with Longwinder Bait, using Shockprod / Stunna peixesing spear**.
