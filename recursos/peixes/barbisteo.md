# Barbisteo

> [!info] Resumo
> Peixe comum, encontrado em **Cambion Drift (Deimos), Cave during Fass / Vome cycle, using Spari / Ebisu peixesing spear**.

**Como conseguir Barbisteo:** aparece em **Cambion Drift (Deimos), Cave during Fass / Vome cycle, using Spari / Ebisu peixesing spear**.
