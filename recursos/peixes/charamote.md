# Charamote

> [!info] Resumo
> Peixe raro, encontrado em **Orb Vallis (Vênus), Cave during Cold / Warm cycle with Charamote Bait, using Shockprod / Stunna peixesing spear**.
> *Descrição no jogo (inglês):* "Its primary function is to reconstruct the bio-material used to regenerate Orokin structures. It can be found in cave pools on Venus."

**Como conseguir Charamote:** aparece em **Orb Vallis (Vênus), Cave during Cold / Warm cycle with Charamote Bait, using Shockprod / Stunna peixesing spear**.
